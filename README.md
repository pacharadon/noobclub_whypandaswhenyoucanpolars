# noobclub — why pandas when you can Polars 🚀

Made by **Pachara Don Stewart**.

**Polars Playground** is a 20-lesson gated course where you learn Polars by running an absurdly diversified business empire:

- 🚀 **Rockets** — telemetry, payloads, fuel ratios, and the occasional failed launch
- 🛒 **Ecommerce** — Shopify, Amazon, and marketplace orders that need filtering, joining, and ranking
- 🌾 **Farms** — sensor rows from Moon Meadow and Rocket Ranch
- 🐄 **Cows** — milk output, feed, and health scores (COW-03 is the star performer, look it up yourself)

You build DataFrames from dicts, filter delivered orders, rank Uber fares within cities, window over rocket missions, and finish with a full launch-day revenue readout. The main path is **pure Polars** — pandas only appears if you deliberately click the spoiler button. No skipping: each lesson stays locked until you pass the one before it.

## Try it

**Live app:** https://pacharadon.github.io/polars-playground/

Single-file app (`index.html`), no build step — React 18 + Tailwind via CDN. Clone it, open it, go.
